## 🎯 Objetivo do Trabalho

Desenvolvimento de um site institucional completo para uma hamburgueria artesanal (**Burguer House**), utilizando as tecnologias fundamentais da Web: **HTML5**, **CSS3** e **JavaScript puro**.

A proposta tem como foco a aplicação prática dos conceitos estudados em aula sobre:
- Estruturação semântica e acessível de páginas web;
- Estilização moderna e layout responsivo com CSS (Flexbox e Grid);
- Manipulação do DOM e interatividade dinâmica com JavaScript;
- Organização profissional de arquivos e boas práticas de código limpo.

## 📄 Páginas do Projeto

O site conta com **5 páginas completas e navegáveis**:

1. **`index.html` (Página Inicial):**
   * Topo com logotipo temático e menu de navegação.
   * Seção *Hero* com imagem em destaque, chamada principal (*CTA*) e botão para o cardápio.
   * Seção com cards dos hambúrgueres mais pedidos da casa.

2. **`cardapio.html` (Cardápio Completo):**
   * Organização por categorias: **Hambúrgueres Artesanais**, **Acompanhamentos** e **Bebidas**.
   * Exibição de foto, nome, ingredientes e preço de cada item.

3. **`galeria.html` (Galeria de Fotos):**
   * Grade fotográfica organizada em colunas (`figure` e `figcaption`) com fotos dos produtos, preparo na grelha e ambiente.

4. **`sobre.html` (Institucional):**
   * Breve narrativa da história da hamburgueria acompanhada de imagem ilustrativa.
   * Bloco estruturado com a **Missão**, **Visão** e **Valores** da empresa.

5. **`contato.html` (Atendimento & Localização):**
   * Endereço físico, telefones, e-mail e horário de funcionamento.
   * Links diretos para redes sociais (Instagram, Facebook e WhatsApp).
   * Formulário com validação via JavaScript e mensagem dinâmica de sucesso na tela.

## 🛠️ Tecnologias e Conceitos Aplicados

### HTML5
* Uso de tags semânticas para SEO e acessibilidade (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<footer>`).
* Criação de formulários estruturados com tipos de input e atributos de validação.

### CSS3
* **Variáveis CSS (`:root`)** para centralização de cores e fácil manutenção.
* **Flexbox** para alinhamento dinâmico do cabeçalho, banner e rodapé.
* **CSS Grid** para organização das grades do cardápio, galeria e blocos de valores.
* **Efeitos de Transição e Hover** suaves nos botões, links e cards.
* **Media Queries (`@media`)** garantindo navegação fluida em telas de celulares.

### JavaScript (Vanilla JS)
* Abertura e fechamento retrátil do menu de navegação no celular (menu hambúrguer).
* Manipulação de eventos (`click`, `submit`, `DOMContentLoaded`).
* Validação de campos obrigatórios e feedback visual no formulário de contato sem recarregar a página.

## 🚀 Como Visualizar o Projeto

### Pré-requisitos
Apenas um navegador web moderno (Google Chrome, Microsoft Edge, Mozilla Firefox, Opera ou Safari).

1. Clone este repositório:

   ```bash

   ```
3. Abra o arquivo `index.html` no seu navegador de preferência dando dois cliques nele ou utilizando a extensão **Live Server** do VS Code.
